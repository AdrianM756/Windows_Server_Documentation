## Installation

On the ```Server Manager```, click ```Add roles and features```, select ```Active Directory Domain Services```.

<br>
<img width="894" height="606" alt="image" src="https://github.com/user-attachments/assets/5e520a94-2a44-4606-91f2-6f727d178bfa" />
<br>
<br>

Click ```Add Features``` then click on ```Next```.
<br>
<img width="894" height="557" alt="image" src="https://github.com/user-attachments/assets/eb07a9bb-56d4-4ca0-8bd1-253f8a535985" />
<br>
<br>

On the ```Select features``` prompt, leave it to default and click ```Next```.
<br>
<img width="687" height="487" alt="image" src="https://github.com/user-attachments/assets/51dbc87e-49d6-4e1c-a936-5f6db85871ea" />
<br>
<br>

On the ```Active Directory Domain Services``` prompt, click ```Next```.
<br>
<img width="685" height="484" alt="image" src="https://github.com/user-attachments/assets/48e14abd-3844-405b-8b05-6602fe343294" />
<br>
<br>

In the ```Confirm installation selections``` prompt, click on the check box```Restart the destination server automatically if required.```.
<br>
<img width="683" height="485" alt="image" src="https://github.com/user-attachments/assets/7da40b67-6d8a-4b73-803a-2f5c1546518a" />
<br>
<br>

A wizard will then appear. Click ```Yes``` to allow the system to restart.
<br>
<img width="387" height="134" alt="image" src="https://github.com/user-attachments/assets/558fbb23-5a53-439d-985a-858a02805f66" />
<br>
<br>

Next, click on ```Install```.
<br>
<img width="687" height="487" alt="image" src="https://github.com/user-attachments/assets/2b971efe-4960-4257-98fb-6b1819fd55f6" />
<br>
<br>

After the installation, click on ```Close```.
<br>
<img width="682" height="480" alt="image" src="https://github.com/user-attachments/assets/348faa0b-15b4-49b0-9aba-50ff5675dc68" />
<br>
<br>


## Setting up Active Directory on Windows Server

On the ```Server Manager```, click on the ```Notifications(flag)```.
<br>
<img width="893" height="95" alt="image" src="https://github.com/user-attachments/assets/fad7f7d4-5ed6-48ba-8d58-ed81cb5c3426" />
<br>
<br>

Select ```Promote this server to a domain controller```.
<br>
<img width="296" height="283" alt="image" src="https://github.com/user-attachments/assets/be06298a-1343-4ec4-8e13-be53eba0b6d6" />
<br>
<br>

On the ```Deployment Configuration``` prompt, select Add a ```new forest``` then, on the ```Root domain name```, type your desired name for the domain controller then click on ```Next```.
<br>
<img width="563" height="415" alt="image" src="https://github.com/user-attachments/assets/1d2530ea-8c10-4320-9e34-1a2051c414a6" />
<br>
<br>

 On the ```Domain Controller Options``` prompt, leave the ```Forest and Domain functional level``` to default. For the ```Directory Services Restore Mode (DSRM)``` type your desired password.
 <br>
<img width="559" height="410" alt="image" src="https://github.com/user-attachments/assets/c3a13538-4882-44d7-9f95-f4fa89cd3bfa" />
<br>
<br>

On the ```DNS Options``` prompt, leave it to default then, click on ```Next```.
<br>
<img width="562" height="414" alt="image" src="https://github.com/user-attachments/assets/277547e7-d3d2-4eb1-b462-5e3fbc5b99de" />
<br>
<br>

In the ```Additional Options``` prompt, leave The ```NetBIOS domain name``` to default then, click on ```Next```.
<br>
<img width="560" height="409" alt="image" src="https://github.com/user-attachments/assets/0a87e28e-4130-4139-8c74-70f25e100c5b" />
<br>
<br>

Leave the ```Path``` to default then, click ```Next```.
<br>
<img width="563" height="415" alt="image" src="https://github.com/user-attachments/assets/385eff47-9761-4aa1-8199-d4430d3bf8f9" />
<br>
<br>

Leave the ```Review Options``` prompt to default then, click on ```Next```.
<br>
<img width="563" height="411" alt="image" src="https://github.com/user-attachments/assets/ddbc4617-22be-42d3-a047-4a6985664e84" />
<br>
<br>

Click ```Install``` to start the installation of Active Directory.
<br>
<img width="556" height="410" alt="image" src="https://github.com/user-attachments/assets/ba662322-a22e-4865-9d30-cc0f625357db" />
<br>
<br>

Click ```Close```.
<br>
<img width="758" height="415" alt="image" src="https://github.com/user-attachments/assets/6b89db0c-d2a7-446c-95cd-0880343def7f" />
<br>
<br>

The Windows Server will restart again.
