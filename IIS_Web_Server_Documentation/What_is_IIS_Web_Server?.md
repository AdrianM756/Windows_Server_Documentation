## IIS Web Server

[IIS Web Sever](https://learn.microsoft.com/en-us/iis/get-started/introduction-to-iis/iis-web-server-overview) (IIS) is a web server developed by Microsoft that operates on the Windows platform. It facilitates the delivery of both static and dynamic web content to users over the internet.
